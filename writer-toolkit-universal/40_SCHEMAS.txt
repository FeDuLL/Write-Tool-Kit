===== ai_decided.schema =====

schema_version: "0.3"
name: ai_decided
required:
  - id
  - field
  - proposal
  - reason
  - source_context
  - reversible
  - author_action_required
  - decision_state
properties:
  reversible: true|false
  author_action_required: true|false
  decision_state:
    enum: PROPOSED | ACCEPTED | REJECTED | DEFERRED
rule: AI-DECIDED records expose assumptions and prevent them from disappearing into prose
rule_2: DERIVED or AI-originated does not imply AUTHOR acceptance

===== audit_coverage.schema =====

schema_version: "0.3"
name: audit_coverage
required:
  - audit_id
  - scope
  - passes
properties:
  scope:
    enum: CHAPTER | SCENE | SEQUENCE | EPISODE | MANUSCRIPT | PROJECT | OTHER
  passes:
    type: list
    item_required:
      - pass_id
      - required
      - executed
      - evidence_available
      - independence_required
      - independence_available
      - result
    item_properties:
      result:
        enum: PASS | FAIL | UNVERIFIED | NOT_APPLICABLE
rule: no FULLY_CHECKED claim until all required passes have a recorded state
rule_2: unit-level coverage does not automatically equal full-manuscript coverage

===== change_log.schema =====

schema_version: "0.3"
name: change_log
entry_required:
  - change_id
  - authority_classification
  - target
  - before
  - after
  - reason
  - author_authorized
  - checkpoint
properties:
  authority_classification:
    enum: REPAIR | OPTIMIZATION | DEVELOPMENT PROPOSAL | AUTHOR DECISION
  change_id: stable change identifier
  target: manuscript, state, style, canon, or other artifact target
  before: prior recorded value or description
  after: resulting value or description
  reason: rationale
  author_authorized: true|false
  checkpoint: checkpoint/version reference
rule: no silent substantive revision
rule_2: audit findings do not mutate the change log as manuscript approval; revision or explicit author action commits changes

===== evidence.schema =====

schema_version: "0.3"
name: evidence
required:
  - source
  - locator
  - excerpt
  - interpretation
  - result
properties:
  result:
    enum: PASS | FAIL | UNVERIFIED | NOT_APPLICABLE
  source: artifact or review source identifier
  locator: stable location within source
  excerpt: relevant evidence fragment
  interpretation: why the evidence supports the recorded result
rule: production report alone is invalid evidence for a HARD-* PASS
rule_2: when independent evidence is required but unavailable, result is UNVERIFIED

===== handoff.schema =====

schema_version: "0.3"
name: handoff
required_order:
  - VERSION
  - PROJECT_ID
  - CURRENT_STAGE
  - CURRENT_UNIT
  - PROJECT_STATUS
  - AUTHOR_DECISIONS
  - AI_DECIDED
  - DEFERRED
  - OPEN_BLOCKERS
  - SCOPE_RECORD
  - STYLE_LOCK
  - ACTIVE_MODULES
  - CAPABILITY_PROFILE
  - RECENT_MANUSCRIPT_CONTEXT
  - CONTINUITY
  - NEXT_AUTHORIZED_ACTION
  - DO_NOT_DO
properties:
  VERSION: toolkit/bootstrap/schema version information
  PROJECT_ID: stable project identifier
  CURRENT_STAGE: stage identifier
  CURRENT_UNIT: production unit or null
  PROJECT_STATUS: project execution status
  AUTHOR_DECISIONS: accepted author decisions relevant to continuation
  AI_DECIDED: ref: ai_decided.schema
  DEFERRED: unresolved decisions that are not yet accepted
  OPEN_BLOCKERS: current blockers
  SCOPE_RECORD: ref: scope_record.schema
  STYLE_LOCK: ref: style_lock.schema
  ACTIVE_MODULES: ref: active_modules.schema
  CAPABILITY_PROFILE: ref: capability_profile.schema
  RECENT_MANUSCRIPT_CONTEXT: navigation context from persisted manuscript
  CONTINUITY: relevant continuity state
  NEXT_AUTHORIZED_ACTION: next allowed operation
  DO_NOT_DO: explicit handoff constraints and protected decisions
rules:
  - handoff is a portable reconstruction aid, not a replacement for manuscript/state
  - DO_NOT_DO is especially important on model/runtime switching
  - unresolved DEFERRED items remain unresolved unless explicitly authorized and decided

schema_version: "0.3"
name: manuscript

  - manuscript_id
  - version
  - form
  - persisted
  - location
  - current_length
  - completed_units
  - checksum_or_integrity_marker
properties:
  manuscript_id: stable manuscript identifier
  version: manuscript version/checkpoint version
  form: declared project form
  persisted: true|false
  location: persisted artifact location or null when runtime cannot persist
  current_length:
    value: ...
    metric: project/form-defined metric
    exactness: EXACT | ESTIMATED | UNKNOWN

  checksum_or_integrity_marker: adapter-dependent integrity marker or null
authority: MANUSCRIPT is authoritative for literal text
completion_rule: unit completion requires TEXT_PERSISTED = YES
conflict_rule: conflicts with state are inspected and resolved explicitly; no blanket precedence rule

===== style_baseline.schema =====

schema_version: "0.3"
name: style_baseline
required:
  - baseline_id
  - excerpts
  - target_notes
  - permitted_variations
  - source_model
  - source_runtime
properties:
  baseline_id: stable identifier for the accepted calibration baseline
  excerpts:
    type: list
    item:
      type: narrative | dialogue | interiority | description
      text: preserved exemplar text
  target_notes: prose contract notes grounded in the calibration
  permitted_variations: allowed variation without treating it as drift
  source_model: model/runtime provenance for the exemplar
  source_runtime: runtime provenance for the exemplar
acceptance_rule: baseline is established only when calibration artifact is preserved and the applicable author interaction is complete
forbidden_claim: adjective-only description is not a sufficient baseline

===== style_lock.schema =====

schema_version: "0.3"
name: style_lock
required:
  - baseline_id
  - locked_at
  - model_profile
  - runtime_profile
  - permitted_variation
  - status
properties:
  baseline_id: reference to style_baseline.schema baseline_id
  locked_at: timestamp or checkpoint reference
  model_profile: current model/runtime profile at lock time
  runtime_profile: execution environment profile at lock time
  permitted_variation: allowed stylistic variation
  status:
    enum: LOCKED | OPEN | SUPERSEDED
rule: Style Lock is an execution reference, not an artistic prison
change_rule: intentional load-bearing deviation requires PROPOSE -> AUTHOR DECISION -> UPDATE STYLE LOCK or REGISTER LOCAL DEVIATION

Design rule: schemas express project/runtime state and persistence contracts; they do not invent artistic defaults.
