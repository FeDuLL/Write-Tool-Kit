# LOC.01 — Language Profile

## Required fields

```text
PRIMARY_LANGUAGE
SECONDARY_LANGUAGES
SCRIPT
REGISTER
DIALECT / SOCIOLECT REQUIREMENTS
ORTHOGRAPHY / SPELLING CONVENTION
PUNCTUATION CONVENTION
TRANSLATION POLICY
TERMINOLOGY POLICY
```

## Runtime rule

Language profile is part of project state and must survive chat/model transitions.

A model may use local linguistic knowledge, but unresolved project-specific terminology remains open rather than silently canonicalized.

===== LOC.02_CULTURAL_AUTHENTICITY.md =====
# LOC.02 — Cultural Authenticity

## Purpose

Audit whether cultural, historical, geographic, and social details are consistent with the declared project setting and intended authenticity level.

## Layers

```text
FACTUAL
DOCUMENTED
PLAUSIBLE
INVENTED-BY-PROJECT
STYLISTICALLY-FILTERED
```

## Rule

Cultural authenticity is calibrated to the project's declared intent. A fantastical or stylized work does not inherit documentary standards unless the contract requires them.

Where external factual verification is required but unavailable, record `UNVERIFIED` rather than fabricate certainty.

===== LOC.03_PUBLISHING_METRICS.md =====
# LOC.03 — Publishing Metrics

## Purpose

Store locale-specific publishing measures without converting them into universal literary quality metrics.

## Example for Russian-language publishing

`Авторский лист (а. л.)` is a publishing/form metric defined as 40,000 printed characters including spaces.

This definition is useful for Russian-language production contexts but does **not** define the ideal size of a novel, chapter, or scene, and does not become a universal project KPI.

## Rule

Any numerical volume target must live in the project `SCOPE_RECORD` rather than this module.

===== LOCALE_MODULE.md =====
# Locale Module

## Module ID

`COND.40_LOCALE`

## Activation

Activate according to the project's actual language / locale / cultural-authenticity requirements.

Current toolkit projects may use Russian (`RU`) as a target locale, but locale logic remains a module rather than a universal literary law.

## Scope

- language profile;
- cultural authenticity;
- publishing metrics and conventions;
- locale-specific spelling, punctuation, terminology, units, and references when requested.

## Principle

The project's declared language and locale are authoritative. A different language's assumptions must not be imported merely because the model was trained on another publishing tradition.
