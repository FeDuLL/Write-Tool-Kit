===== IP.01_ASSET_REGISTER.md =====
# IP.01 — Asset Register

## Purpose

Track potentially reusable or cross-media-sensitive assets without conflating reuse value with canon status.

## Suggested fields

```text
ASSET_ID
ASSET_NAME
TYPE
CANON_STATUS
CORE_TRUTH_REF
MEDIUMS
ADAPTATION_NOTES
AUDIENCE_EXPOSURE
LICENSE / MARKETING NOTES
RESTRICTIONS
```

## Canon rule

Being useful for games, film, merchandising, or marketing does not promote an asset into canon.

===== IP.02_MEDIUM_SEPARATION.md =====
# IP.02 — Medium Separation

## Four-layer model

### CORE_WORLD_TRUTH
What is true within the approved world model.

### MEDIUM_ADAPTATION
What is altered for a specific medium's constraints or affordances.

### AUDIENCE_KNOWLEDGE
What a specific audience or release actually exposes.

### MARKETING / LICENSE EXPRESSION
How the property is represented commercially without necessarily stating canon.

## Change rule

Every proposed cross-media difference must be classified before adoption.

If a change would alter core world truth, it becomes an author-level canon decision rather than an adaptation convenience.

===== IP.03_NOVEL_FIRST_GATE.md =====
# IP.03 — Novel-First Gate

## Purpose

Prevent speculative franchise logic from displacing the primary literary work.

## Gate questions

```text
Is the literary promise still intact?
Does the current manuscript work on its own terms?
Is a proposed cross-media feature necessary to solve a literary problem?
Does the change preserve canon boundaries?
```

## Outcome

Cross-media ideas that do not improve or protect the literary work remain external proposals rather than hidden production requirements.

===== IP_CROSSMEDIA_MODULE.md =====
# IP / Cross-Media Module

## Module ID

`COND.20_IP`

## Activation

Activate when:

```text
IP = ON
```

or

```text
CROSS_MEDIA = ON
```

## Separation contract

```text
CORE_WORLD_TRUTH
MEDIUM_ADAPTATION
AUDIENCE_KNOWLEDGE
MARKETING / LICENSE EXPRESSION
```

## Rule

A medium-specific convenience must not silently become a change to core world truth.

A marketing expression is not itself canon.

Audience knowledge may differ from internal world truth.

## Literary-primary rule

When literature is the primary product, the novel/script remains the authoritative literary artifact. Cross-media opportunities are evaluated around it rather than silently reshaping it.
