# Package Transfer Record

This repository is the GitHub home for the WRITER-TOOLKIT v0.3 development.

The canonical working package used during development contains:

- Native Skill distribution;
- Universal TXT distribution;
- architecture/build specifications;
- schemas;
- templates;
- adapters;
- conditional modules;
- development/production/revision engines;
- audit contracts;
- bootstrap and handoff wrappers;
- Phase H tests and fixtures;
- anti-drift validation artifacts.

The transfer is being performed from the final v0.3 anti-drift package. The GitHub repository is intended to become the durable, reviewable source tree rather than a collection of unrelated audit archives.

## Canonical source hierarchy

1. Architecture Spec
2. Build Spec
3. Core/runtime contracts
4. Project State schemas
5. Engines/modules/adapters
6. Tests and fixtures
7. Distribution wrappers
8. Reports and historical documentation

When a generated report conflicts with a canonical contract, the conflict must be investigated rather than resolved by silently changing the contract.
