# DEV.05_CAUSALITY

**ID:** `DEV.05_CAUSALITY`

## CANONICAL CHAIN

```text
CAUSE
→ CHOICE / ACTION
→ CONSEQUENCE
→ NEW SITUATION
```

## FAIL

- coincidence performs load-bearing causal work without justification;
- protagonist lacks causal agency where agency is promised.

## RULE

Causality is a diagnostic model. It is not a command to impose the same
beat structure on every literary form.
