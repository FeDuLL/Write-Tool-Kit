# DEV.01_STORY_CORE

**ID:** `DEV.01_STORY_CORE`

## CANONICAL FIELDS

```text
PREMISE
CENTRAL_CONFLICT
PROTAGONIST
DESIRE
NEED
STAKES
PROMISE
ENDING
THEMATIC_PRESSURE
```

## RULE

No field may become universal genre logic.

The fields describe the project; they do not force a specific genre, framework,
arc shape or ending.

## GATE

Story core must be sufficiently explicit for the selected development mode,
without inventing missing author decisions as accepted facts.
