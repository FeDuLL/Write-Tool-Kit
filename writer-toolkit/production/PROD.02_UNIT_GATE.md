# PROD.02_UNIT_GATE

**ID:** `PROD.02_UNIT_GATE`

## TRIGGER

Immediately before writing the current production unit.

## PRECONDITIONS / CHECKS

```text
CURRENT STAGE
CURRENT STATE
ACTIVE MODULES
RELEVANT PREVIOUS STATE
AUTHOR DECISIONS
STYLE LOCK
OPEN BLOCKERS
```

Also verify:

```text
NO BLOCKING HARD CONFLICT
NO REQUIRED UNRESOLVED LOAD-BEARING DECISION
```

## OUTPUT

`READY_TO_WRITE` or blocker list.

## FAIL

`UNIT_NOT_READY`
