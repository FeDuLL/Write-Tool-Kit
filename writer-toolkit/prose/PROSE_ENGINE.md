# PROSE ENGINE

**Layer:** ENGINE  
**Activation:** when prose production is applicable  
**Dependencies:** Creative Brief, Form Contract, Core state/evidence/change control

## PURPOSE

Перевести авторские требования к прозе в исполнимый Prose Contract, создать
и сохранить Style Baseline, затем применять Style Lock без превращения
эталона в художественную клетку.

## PROCESS

```text
PROSE CONTRACT
→ STYLE BASELINE
→ CALIBRATION
→ STYLE LOCK
→ PRODUCTION
→ STYLE DRIFT AUDIT
```

## CORE RULES

- No universal numeric prose KPI.
- Style target must be explicit enough to execute.
- Baseline is an artifact, not an adjective list.
- Style Lock is an execution reference.
- Intentional deviation requires proposal + author decision.
- A new model/runtime switch triggers baseline/lock re-anchoring as specified
  by the project/bootstrap layer.

## OUTPUTS

- `PROSE_CONTRACT`
- `STYLE_BASELINE`
- `STYLE_LOCK`
- `STYLE_DRIFT_FINDINGS`
