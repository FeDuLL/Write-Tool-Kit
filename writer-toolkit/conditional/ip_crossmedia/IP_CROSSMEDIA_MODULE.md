# IP / Cross-Media Module

## Module ID

`COND.20_IP`

## Activation

Activate when:

```text
IP = ON
```

or

```text
CROSS_MEDIA = ON
```

## Separation contract

```text
CORE_WORLD_TRUTH
MEDIUM_ADAPTATION
AUDIENCE_KNOWLEDGE
MARKETING / LICENSE EXPRESSION
```

## Rule

A medium-specific convenience must not silently become a change to core world truth.

A marketing expression is not itself canon.

Audience knowledge may differ from internal world truth.

## Literary-primary rule

When literature is the primary product, the novel/script remains the authoritative literary artifact. Cross-media opportunities are evaluated around it rather than silently reshaping it.
