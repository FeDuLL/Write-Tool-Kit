# Genre Contract Module

## Module ID

`COND.50_GENRE_CONTRACT`

## Activation

Activate when the author requests genre contracting or when genre materially affects the reader promise and audit scope.

## Contract fields

```text
READER_PROMISE
EXPECTED_EFFECT
CONVENTIONAL_ELEMENTS
OPTIONAL_CONVENTIONS
DELIBERATE_DEVIATIONS
AUDIT_RISKS
```

## Principle

Genre conventions are diagnostic lenses, not immutable laws.

Structural frameworks and genre models may inform diagnosis, but they never override an explicit authorial mode merely because a framework predicts a different arrangement.
