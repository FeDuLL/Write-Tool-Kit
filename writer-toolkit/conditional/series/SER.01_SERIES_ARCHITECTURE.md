# SER.01 — Series Architecture

## Purpose

Model the relationship between the current book and any approved larger arc without allowing future plans to distort the current manuscript by default.

## Required fields

```text
CURRENT_BOOK_PROMISE
CURRENT_BOOK_SCOPE
BOOK_RESOLUTION
SERIES_ARC_STATUS
FUTURE_SEEDS
RESERVED_REVEALS
ESCALATION_PLAN
UNUSED_OPTIONALITY
```

## Rule

A future seed is a design reserve, not an accepted event.

A future reveal is not current canon unless explicitly accepted as such.
