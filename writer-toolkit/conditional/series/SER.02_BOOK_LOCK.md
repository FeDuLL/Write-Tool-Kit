# SER.02 — Book Lock

## Purpose

Protect the current book from uncontrolled series expansion during production.

## Book Lock records

```text
LOCKED_BOOK_SCOPE
LOCKED_END_STATE
LOCKED_LOAD_BEARING_ARCS
RESERVED_SERIES_SPACE
OPEN_SERIES_OPTIONS
DEFERRED_SERIES_DECISIONS
```

## Gate

When the current-book lock is active, a series idea that changes a load-bearing current-book element becomes a development proposal and requires the appropriate author decision.

Silence is not approval.
