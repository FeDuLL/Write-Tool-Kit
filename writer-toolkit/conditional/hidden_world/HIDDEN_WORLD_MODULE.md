# Hidden World Module

## Module ID

`COND.01_HIDDEN_WORLD`

## Activation

Activate only when the project contains a required concealed layer such as:

```text
HIDDEN_WORLD = ON
```

or an equivalent explicit hard reveal requirement.

Typical activation reasons may include concealed ontology, hidden identity, secret system rules, delayed cosmology, or a mystery whose fairness depends on controlled information release.

## Inputs

- `WORLD_TRUTH`
- `SURFACE_WORLD`
- `CHARACTER_KNOWLEDGE`
- `READER_KNOWLEDGE`
- `REVEAL_PLAN`

## Outputs

```text
HIDDEN_ONTOLOGY
SURFACE_MODEL
EPISTEMIC_BRIDGES
REVEAL_STATE
DISCOVERY_CONSTRAINTS
```

## Operating rules

1. Hidden truth and apparent truth are stored separately.
2. Character knowledge is not inferred from model knowledge.
3. A reveal must have an information path appropriate to the chosen viewpoint and form.
4. A secret is not automatically fair merely because clues exist.
5. First-read inference claims require independent evidence; unavailable independence is `UNVERIFIED`.
6. This module never authorizes the model to reveal or redefine the hidden truth on its own.

## Inactive behavior

When the module is OFF, no hidden ontology, reveal schedule, concealment audit, or secret-state persistence is created merely by stylistic inference.
