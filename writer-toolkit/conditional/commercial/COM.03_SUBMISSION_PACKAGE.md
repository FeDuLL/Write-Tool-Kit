# COM.03 — Submission Package

## Purpose

Build a publication / submission layer that accurately represents the approved manuscript.

## Possible components

```text
TITLE
ONE-LINE PITCH
LOGLINE / PREMISE
SYNOPSIS
AUTHOR BIO (when supplied)
GENRE / POSITIONING
TARGET AUDIENCE
COMPARABLES / MARKET CONTEXT
SUBMISSION NOTE
```

## Integrity rule

Submission materials may simplify presentation, but must not contradict the manuscript or invent achievements, audience data, or market facts.

Any commercial claim without adequate evidence remains qualified or `UNTESTED`.
