# Commercial Module

## Module ID

`COND.30_COMMERCIAL`

## Activation

Activate only on explicit author request or when commercial evaluation is a declared project requirement.

## Commercial hypothesis states

```text
HYPOTHESIS
EVIDENCE
STATUS
SUPPORTED
MIXED
WEAKENED
UNTESTED
```

## Commercial scope

Commercial evidence may inform:

- positioning;
- title / blurb / package;
- target audience definition;
- channel or submission strategy;
- format or market hypotheses.

## Commercial firewall

Commercial considerations cannot silently rewrite:

- artistic core;
- character psychology;
- ending;
- theme;
- approved world truth;
- authorial meaning.

Any such change requires an explicit proposal and the appropriate author decision.
